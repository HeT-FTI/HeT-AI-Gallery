NNSeg 项目文档

概述

NNSeg 是一个面向食材场景实例分割的 C/C++ 推理库。项目提供现代化 C++ API、可供 C 运行时集成的稳定 C ABI，以及基于 Conan 的打包与测试流程。

本文档覆盖内容

  • 通过 CMake 与 Conan 的构建与打包集成。

  • C++ 与 C 双接口的运行时使用方法。

  • 基于 metadata 的项目配置与 CI 开关。

  • 输入输出约束、错误行为与验证范围。

快速开始

# Build and run test_package in one step
conan create . -s build_type=Debug --build=missing

# Build release package
conan create . -s build_type=Release --build=missing

# Build docs (Doxygen + Sphinx)
uv run ./docs/build.py

仓库结构

nn_seg/
├── include/                 # Public C/C++ headers (nnseg.hpp, nnseg_c.h, ...)
├── src/                     # Runtime implementation and C bridge
├── api/                     # Optional Python binding source
├── test_package/            # Integration executable + unit/stress tests
├── benchmark/               # On-board benchmark framework
├── docs/                    # Doxygen + Sphinx source
├── CMakeLists.txt           # Build graph and target definitions
├── conanfile.py             # Conan recipe
└── metadata.json            # Build/docs/CI control plane
