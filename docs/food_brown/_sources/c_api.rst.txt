_`C API Guide`
==============

_`nnseg C Interface`
--------------------

Defined in `include/nnseg_c.h`.

- Lifecycle: `nnseg_create` -> `nnseg_init`/`nnseg_init_from_file` -> `nnseg_predict` -> `nnseg_result_release` -> `nnseg_destroy`
- Status enum: `nnseg_status_t`

.. code-block:: c

   nnseg_engine_t *engine = nnseg_create();
   if (!engine) {
       return NNSEG_STATUS_NO_MEMORY;
   }

   nnseg_config_t cfg = {0};
   cfg.model_path = "model.onnx";
   cfg.model_type = "yolov11";

   int32_t st = nnseg_init(engine, &cfg);
   if (st != NNSEG_STATUS_OK) {
       nnseg_destroy(engine);
       return st;
   }

- Lifecycle: `food_browning_create` -> `food_browning_init`/`food_browning_init_from_file` -> `food_browning_analyze` -> `food_browning_result_release` -> `food_browning_destroy`
