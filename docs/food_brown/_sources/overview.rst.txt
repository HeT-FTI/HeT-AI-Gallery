_`Project Overview`
===================

_`Positioning`
--------------

This project provides a C/C++ SDK for food browning analysis with two core parts:

- `nnseg`: instance segmentation engine.
- `food_browning`: browning maturity estimation over segmented instances.

_`Scope`
--------

- Input: image frame and optional runtime/model configuration.
- Output: instance-level segmentation result, browning score, and error information.
- Typical use cases: stage detection during baking, doneness window detection, and overbake warning.
