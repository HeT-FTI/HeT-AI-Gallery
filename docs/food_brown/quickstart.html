2. 快速开始

2.1. 环境准备

  • Python 3.10+

  • Conan 2+

  • CMake

  • Doxygen 和 Graphviz（完整文档流水线所需）

2.2. 构建与测试

# 1) Build and test (Debug profile, coverage-friendly)
conan create . -s build_type=Debug --build=missing

# 2) Build documentation through the project entrypoint
python ./docs/build.py

2.3. 最小运行流程

  1. 初始化 nnseg 并执行 Predict。

  2. 初始化 food_browning 并执行 Analyze。

  3. 从 BrowningResult.items 读取实例级成熟度，并在 ok 为 false 时处理错误。
