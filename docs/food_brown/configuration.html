5. 配置说明

5.1. 分割配置：SegConfig

字段定义见 include/nnseg_types.hpp::SegConfig。

  • model_path：模型文件路径。

  • model_type：模型类型名称，默认 yolov11。

  • model_input_width / model_input_height：模型输入尺寸。

  • conf_threshold / iou_threshold：置信度与 NMS 阈值。

  • max_tracking_distance / max_disappeared_frames：跟踪行为参数。

5.2. 褐变配置：BrowningConfig

字段定义见 include/food_browning.hpp::BrowningConfig。

  • default_profile：未匹配类别的默认画像配置。

  • profiles_by_class_id：按类别覆盖画像配置。

  • debug：调试日志开关。

5.3. 调参建议

  • 建议先固定模型类型和输入尺寸，再调整阈值。

  • 建议按食物类别维护独立的 FoodProfile。

  • 生产环境建议关闭 debug，仅在排障时临时开启。
