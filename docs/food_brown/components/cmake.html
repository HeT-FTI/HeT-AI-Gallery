CMakeLists 配置

概述

CMakeLists.txt 文件是 fcpp 项目的核心构建配置文件，负责项目构建、依赖管理和模块编译。

主要特性

  • 项目初始化与元数据解析

  • 自动源文件收集与目标创建

  • 依赖管理与链接

  • C++ 模块支持配置

  • 安装规则定义

主要配置项

CMake 配置会自动从 metadata.json 读取项目信息，从 include 和 src 目录收集源文件，为 C 和 C++ 组件分别创建静态库，并配置 C++23 及以上版本的模块支持。

平台特定的模块编译通过针对 MSVC (.ixx 文件) 和 GCC/Clang (.cppm 文件) 的适当设置进行处理。该配置还包含库和头文件的安装规则。
