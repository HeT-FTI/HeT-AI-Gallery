2. Third-party code: what we link, and what we may read

Two questions, two registries. deps.json records what this library links and where each package may appear; reuse-audit.json records the licence of every upstream project it is allowed to read from. The library is Apache-2.0 and is meant to be linked into products, so a single copyleft source file would relicense the whole thing — which is why the second table exists before anyone opens an upstream repository.

2.1. What this project links

Every entry below is declared in conandata.yml. Nothing else is linked, vendored or copied. The same registry drives both checks: an #include of a package outside the paths named here fails, and so does a package declared in conandata.yml that nothing includes.

2.2. etl 20.47.1

Why it is here. Provenance for the parts of a motor controller that are easy to get subtly wrong and cheap to get from a tested, fielded embedded library: CRC (a wrong polynomial is silent), bit-stream packing for non-byte-aligned encoder frames, byte order, and fixed-capacity text formatting without allocation.

What it buys. A second, independently written implementation to compare against our own on every push (the cross-check cases), and a tested bit manipulator behind the compiled face. It is evidence, not convenience: 'our CRC agrees with ETL byte for byte over 0..64 byte frames' is a sentence a reviewer can check.

Verdict. INTERNAL ONLY. Every candidate header costs a consumer 7x-34x the price of the whole foc include face, so ETL may not appear on any public header. It is a cpp bucket (conan) dependency, which is visible to the recipe, while include/** stays free of it: the include face is what a consumer actually pays for.

2.5. What we may read from

Before reading an upstream project closely, vendoring it or copying a function out of it, look it up here. "Behaviour" means writing our own test for what the other project guarantees; "code" means copying, and it is only available under a permissive licence.

SimpleFOC — MIT, may be vendored, keep the notice

Behaviour spec and the HAL breadth checklist. Not code: its Arduino/global-object model conflicts with the rule that include/ is allocation-free and exception-free, and with policy composition having no globals. Evidence. LICENSE, Copyright (c) 2020 Antun Skuric

moteus — Apache-2.0, may be vendored, keep the notice

The best reference for the command surface — field semantics, NaN meaning hold position, the gain scales — and for the field-weakening calibration flow. Same licence family as ours. Evidence. README, licence section

VESC (bldc) — GPLv3, never

Capability and parameter semantics only. Copyleft is viral and would end the Apache-2.0 licence and any commercial use: do not copy code or comments, write the behaviour down as our own test and satisfy that. Evidence. README badge and body

miniFOC — AGPL-3.0, never

Reference for 'low-cost hardware, no current loop' only. The network clause is poison for a library. Evidence. README body

SguanFOC — MIT, may be vendored, keep the notice

Thinking reference only: never in the build, never in the library. conventions.rst records why it is also the one external reference whose numbers this project refuses to compare against. Evidence. LICENSE, Copyright (c) 2026 星必尘Sguan

ODrive (firmware) — MIT, may be vendored, keep the notice

Behaviour spec first — spinout detection, input modes, anticogging, the torque-mode velocity limiter. Code only with the notice. Verified by cloning, which also pins the commit the conclusion rests on. Evidence. LICENSE.md first line, Copyright (c) 2016-2018 ODrive Robotics, repo 3a2e4dd1; three web fetches had failed before a clone worked

ST MCSDK / TI InstaSPIN / FpOC — unverified, unverified

Treat like ODrive until verified: behaviour first, code never. Evidence. not fetched

ETL — MIT, not vendored

An internal dependency and an independent witness: src/** and the tests may include it, a public header may not. The cross-check cases are the point — our CRC agrees with theirs byte for byte. The measured cost of the other choice is in deps.json. Evidence. LICENSE in the conan package, © John Wellbelove and contributors

2.6. Working rules

Two ways to integrate, and only one is about code

Behaviour integration, always allowed. Write our own test that encodes what the other project guarantees, then satisfy it. No licence question arises, and the test is the artefact that survives.

Code integration, permissive licences only. Copy, keep the notice, extend NOTICE, and let gates.py license keep everyone honest. A vendored subtree that is legitimately copyleft needs a scope line in .github/misc/.license-guard.txt and an entry in NOTICE; the library default stays permissive.

How to verify a licence: clone it, do not fetch it

A web fetch cannot extract a plain-text LICENSE, and a clone also pins the exact commit the conclusion rests on — which a web page never does. workspace/ is git-ignored, so the reference copy never reaches a commit, but the conclusion and the commit hash do.

Hardware is not code

Driving hardware designed for another project needs no licence at all, and it is the cheapest real integration available: implement the five HAL interfaces (Pwm, CurrentSense, PositionSensor, DcLink, Clock) for that board and the library serves it.
