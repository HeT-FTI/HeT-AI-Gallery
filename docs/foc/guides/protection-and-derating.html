1.1.10. Health and protection

The task: decide what a drive does when something is wrong -- how long an overload may last, what happens after it trips, and what the answers must not be confused with.

1.1.10.1. What you need

  • foc/core/protection.hpp -- the mechanism matrix (over-current, over- and under-voltage, temperature, i2t, stall, lost sync), the ranked fault, the latched mask, and the derated current limit that goes with it.

  • foc/core/watchdog.hpp -- silence measurement: Feeding, Expired, ClockLost, and the distinction between kicking and polling.

  • foc/core/thermal_limit.hpp -- the winding's own first-order model, which is where the temperature the protector is fed with comes from.

  • foc/core/brake_chopper.hpp -- the bus over-voltage path, with the brake resistor's thermal budget rather than a voltage-only decision.

  • foc/core/auto_tune.hpp and foc/core/commissioning.hpp -- the parameter path: where the numbers a protection compares against are supposed to come from. The procedure that produces them is Outer-loop self-tuning, not a constant.

1.1.10.2. A minimal program

docs/doxygen/dox/demos/protection-and-derating.cxx sweeps the i2t budget below the hard trip, reads the derating curve across the trip temperature, walks the latch through a trip and a reset, asks a watchdog past its window, and pushes the bus into a brake chopper. The same file produces this page's figure.

 54// that the one input under test is the only thing that can trip.

 69auto main(int argc, char **argv) -> int {
 70    const char *csv_path = nullptr;
 71    if (argc == 3 && std::strcmp(argv[1], "--csv") == 0) {
 72        csv_path = argv[2];
 73    } else if (argc != 1) {
 74        std::fprintf(stderr, "usage: %s [--csv <path>]\n", argv[0]);
 75        return 2;
 76    }
 77
 78    FILE *csv = nullptr;
 79    if (csv_path != nullptr) {
 80        csv = std::fopen(csv_path, "w");
 81        if (csv == nullptr) {
 82            std::perror("fopen");
 83            return 1;
 84        }
 85        std::fprintf(csv, "kind,x,value,flag\n");

 88    constexpr float kDt = 100.0e-6F; // 10 kHz
 89    const foc::core::ProtectionConfig config = protection_config();
 90
 91    // ------------------------------------------------------------- i2t budget
 92    // The budget is `i_cont^2 * tau`, so the continuous rating sits *at* the
 93    // limit forever and only the excess spends the margin. Below the hard trip
 94    // (4 A) the question is therefore not "does it trip" but "how long", and that
 95    // time goes to infinity as the current approaches the rating.
 96    // 预算是 `i_cont²·τ`，所以连续额定永远**坐在**限值上，只有超出的部分花掉余量。在硬跳闸
 97    // （4 A）以下，问题不是"跳不跳"而是"多久"，而这个时长在电流逼近额定时趋于无穷。
 98    std::printf("protection: %.0f A hard, %.1f A continuous, budget %.1f A^2*s, %.1f s cooling\n",
 99                static_cast<double>(config.i_hard_a), static_cast<double>(config.i_max_a),
100                static_cast<double>(config.i2t_a2s), static_cast<double>(config.i2t_cooling_s));
101    std::printf("%10s %14s %s\n", "i (A)", "trip after (s)", "fault");
102    for (int step = 0; step <= 24; ++step) {
103        const float current_a = 3.02F + (0.04F * static_cast<float>(step));
104        foc::core::Protector protector(config);
105        float time_s = 0.0F;
106        foc::core::ProtectionOutput output{};
107        while (time_s < 60.0F) {
108            output = protector.step(healthy_input(current_a, 40.0F), kDt);
109            time_s += kDt;
110            if (output.fault != foc::core::FaultCode::None) {
111                break;
112            }
113        }
114        const bool tripped = output.fault != foc::core::FaultCode::None;
115        if (csv != nullptr) {
116            std::fprintf(csv, "i2t,%.3f,%.5f,%d\n", static_cast<double>(current_a),
117                         static_cast<double>(tripped ? time_s : 0.0F), tripped ? 1 : 0);
118        } else if ((step % 4) == 0) {
119            if (tripped) {
120                std::printf("%10.3f %14.4f %s\n", static_cast<double>(current_a), static_cast<double>(time_s),
121                            "I2t");
122            } else {
123                std::printf("%10.3f %14s %s\n", static_cast<double>(current_a), "never", "-");
124            }
125        }
126    }

128    // ------------------------------------------------------------ derating
129    // The continuous limit is a curve in temperature; the trip is a threshold.
130    // They are not two spellings of one decision: at the trip temperature the
131    // curve still allows current, so a controller that only reads the curve never
132    // trips, and a controller that only reads the trip runs at full current right
133    // up to it.
134    // 连续限幅是温度上的一条曲线；跳闸是一个阈值。它们不是同一个决定的两种写法：在跳闸温度上
135    // 曲线仍然允许电流，所以只读曲线的控制器永不跳闸，而只读跳闸的控制器会把满电流一直用到那一点。
136    std::printf("\n%-10s %10s %10s\n", "T (C)", "limit (A)", "trip?");
137    for (int step = 0; step <= 120; step += 10) {
138        const float temperature_c = static_cast<float>(step);
139        const float limit_a = foc::core::Protector(config).derated_limit(temperature_c);
140        const bool trip = temperature_c > config.t_trip_c;
141        if (csv != nullptr) {
142            std::fprintf(csv, "derate,%.1f,%.5f,%d\n", static_cast<double>(temperature_c),
143                         static_cast<double>(limit_a), trip ? 1 : 0);
144        } else {
145            std::printf("%-10.0f %10.4f %10s\n", static_cast<double>(temperature_c), static_cast<double>(limit_a),
146                        trip ? "trip" : "-");
147        }
148    }
149
150    // The trip threshold on its own row: it is a configuration number, not a
151    // sample of the curve, and a figure that drew it from the curve would be
152    // showing the curve's zero crossing instead of the trip.
153    // 跳闸阈值单独一行：它是配置里的数，不是曲线上的采样点；从曲线里取它来画，画出来的会是
154    // 曲线的零点而不是跳闸点。
155    if (csv != nullptr) {
156        const float at_trip_a = foc::core::Protector(config).derated_limit(config.t_trip_c);
157        std::fprintf(csv, "trip,%.1f,%.5f,0\n", static_cast<double>(config.t_trip_c), static_cast<double>(at_trip_a));
158    }
159
160    // --------------------------------------------------------------- latching
161    // An over-current trip is latched: when the current comes back inside the
162    // limits the output stays disabled, because the reason it tripped has not been
163    // looked at yet. `reset()` is the only way out, and it is the caller's
164    // decision -- a drive that cleared itself would restart into the same fault.
165    // 过流跳闸是锁存的：电流回到限值以内之后输出仍然被禁，因为跳闸的原因还没有人看过。
166    // `reset()` 是唯一的出路，而且是调用方的决定——自己复位的驱动器会一头撞回同一个故障。
167    {
168        foc::core::Protector protector(config);
169        float time_s = 0.0F;
170        foc::core::FaultCode previous_fault = foc::core::FaultCode::None;
171        std::printf("\nlatch timeline (10 ms at 4.5 A, then healthy input):\n");
172        for (int step = 0; step < 300; ++step) {
173            const float current_a = (time_s < 0.010F) ? 4.5F : 1.0F;
174            const foc::core::ProtectionOutput output = protector.step(healthy_input(current_a, 40.0F), kDt);
175            time_s += kDt;
176            if (output.fault != foc::core::FaultCode::None && previous_fault == foc::core::FaultCode::None) {
177                std::printf("  4.5 A at %.1f ms -> fault, output_allowed %d\n", static_cast<double>(1000.0F * time_s),
178                            output.output_allowed ? 1 : 0);
179            }
180            if (current_a < 2.0F && (step == 110 || step == 299)) {
181                std::printf("  back to 1 A at %.1f ms -> output_allowed %d (latched)\n",
182                            static_cast<double>(1000.0F * time_s), output.output_allowed ? 1 : 0);
183            }
184            previous_fault = output.fault;
185            if ((step % 20) == 0 || step == 299) {
186                if (csv != nullptr) {
187                    std::fprintf(csv, "latch,%.3f,%.4f,%d\n", static_cast<double>(1000.0F * time_s),
188                                 static_cast<double>(output.i_limit_a), output.output_allowed ? 1 : 0);
189                }
190            }
191        }
192        foc::core::ProtectionOutput after = protector.step(healthy_input(1.0F, 40.0F), kDt);
193        std::printf("  healthy current, no reset   -> output_allowed %d, limit %.2f A\n", after.output_allowed ? 1 : 0,
194                    static_cast<double>(after.i_limit_a));
195        protector.reset();
196        after = protector.step(healthy_input(1.0F, 40.0F), kDt);
197        std::printf("  after reset()               -> output_allowed %d, limit %.2f A\n", after.output_allowed ? 1 : 0,
198                    static_cast<double>(after.i_limit_a));
199    }

201    // -------------------------------------------------------------- watchdog
202    // It measures silence, not progress. A loop that is alive but stuck still gets
203    // kicked if the kick sits in the wrong place; a loop that is dead cannot kick.
204    // 它量的是**沉默**，不是进展。活着但卡住的循环，如果喂狗写错了地方，照样会被喂；而死的循环
205    // 喂不了。
206    {
207        constexpr std::uint64_t kWindowNs = 5'000'000ULL; // 5 ms
208        foc::core::Watchdog watchdog;
209        if (watchdog.setup(foc::core::WatchdogConfig{kWindowNs}) != foc::ErrorCode::Ok) {
210            std::printf("  watchdog refused the window\n");
211        }
212        static const char *names[] = {"unarmed", "feeding", "expired", "clock lost"};
213        for (std::uint64_t now_ns = 1'000'000ULL; now_ns <= 3'000'000ULL; now_ns += 1'000'000ULL) {
214            const foc::core::WatchdogReport report = watchdog.kick(now_ns);
215            std::printf("  watchdog kick at %llu ms -> %s, %llu ms left\n",
216                        static_cast<unsigned long long>(now_ns / 1'000'000ULL), names[static_cast<int>(report.state)],
217                        static_cast<unsigned long long>(report.remaining_ns / 1'000'000ULL));
218        }
219        // Asking is not kicking: `poll()` says what the state is at that instant
220        // without moving the deadline, which is what a supervisor does on its own
221        // schedule -- the loop that must be watched cannot be the one doing the
222        // watching.
223        // 问不是喂：`poll()` 说出那一刻的状态而不动截止时间，这正是监督者按自己的节奏做的事——
224        // 被看的那个环路不能同时是看的那个。
225        const foc::core::WatchdogReport expired = watchdog.poll(9'000'000ULL);
226        std::printf("  watchdog asked at 9 ms (no kick since 3) -> %s, silence %llu ms\n",
227                    names[static_cast<int>(expired.state)],
228                    static_cast<unsigned long long>(expired.step_ns / 1'000'000ULL));
229        const foc::core::WatchdogReport late = watchdog.kick(10'000'000ULL);
230        std::printf("  a kick after the trip -> %s (it does not clear itself)\n", names[static_cast<int>(late.state)]);
231    }
232
233    // ---------------------------------------------------------- brake chopper
234    // The resistor is a budget, not a switch: its thermal mass is what decides how
235    // long a regen event may last, and a chopper that only follows the voltage can
236    // burn itself out while holding the bus perfectly.
237    // 电阻是一个预算，不是一个开关：它的热容决定一次回馈能持续多久，而一个只看电压的斩波器
238    // 可以在把母线守得很好的同时把自己烧掉。
239    {
240        foc::core::BrakeChopper chopper(
241            foc::core::BrakeChopperConfig{32.0F, 30.0F, 10.0F, 0.9F, 100.0e-6F, 100.0e-6F, 0.5F, 2.0F});
242        std::printf("\nbrake chopper, bus ramps to 34 V then falls back:\n");
243        for (int step = 0; step < 60; ++step) {
244            const float v_bus = (step < 30) ? (28.0F + (0.2F * static_cast<float>(step)))
245                                            : (34.0F - (0.2F * static_cast<float>(step - 30)));
246            const foc::core::BrakeChopperOutput output = chopper.step(v_bus, 1.0e-3F);
247            if ((step % 10) == 0 || (step == 15 && output.on)) {
248                std::printf("  v_bus %5.1f V -> on %d, duty %.2f, i2t %.3f A^2*s\n", static_cast<double>(v_bus),
249                            output.on ? 1 : 0, static_cast<double>(output.duty), static_cast<double>(output.i2t_a2s));
250            }
251        }
252    }
253
254    if (csv != nullptr) {
255        std::fclose(csv);
256        std::printf("wrote %s\n", csv_path);
257        return 0;
258    }
259    return 0;

1.1.10.3. Where the numbers come from

  • The i2t budget is not "rated current for one second". It is i_continuous^2 * tau, the equilibrium of the thermal model, and that identity is what pins the units down: a budget that is anything else either trips a machine running at its own nameplate or never trips at all.

  • The cooling time constant is the winding's, not a tuning number. It is the same quantity thermal_limit.hpp models, and if the two disagree the budget is describing a different machine from the one the temperature comes from.

  • The trip and the derating endpoints come from the insulation class and the magnet, and the third temperature -- where derating starts -- is where the drive begins to give up torque in order to stay below the other two.

  • The watchdog window is set by the slowest legitimate silence in the system, not by the control period: too tight and it trips on a long branch, too loose and it reports a dead loop as healthy.

  • The brake resistor's budget is its thermal mass; duty_max and the minimum on/off times belong to the gate driver. The chopper's job is to spend the first without violating the second.

1.1.10.4. How it goes wrong

  1. The budget read as a threshold. "It trips above rated current" is the wrong mental model: at the rated current the budget's equilibrium is the budget, so the time to trip is infinite, and just above it the time is finite but long. A supervisor that expects a threshold will size a contactor for the wrong event.

  2. Derating and tripping treated as one decision. They are two numbers with a gap between them: at the trip temperature the derating curve still allows current. A controller that only applies the curve never trips, and one that only applies the trip runs at full current right up to the wire's limit.

  3. A trip that clears itself. The output stays disabled after the current comes back, and that is deliberate: the reason it tripped has not been looked at. reset() is the caller's explicit decision, and a drive that auto-reset would restart into the same fault at a rate set by the fault itself.

  4. A watchdog kicked from the wrong place. It measures silence, not progress. Kicking it from the same loop that must be watched -- or from an interrupt that keeps running while the loop is stuck -- produces a perfectly fed watchdog attached to a dead controller.

  5. A chopper that only watches the bus. Holding the bus at the threshold with a resistor whose thermal budget is spent is a controlled way to burn the resistor. The budget latches the duty to zero for that reason.

1.1.10.5. Evidence

Five claim rows cover this page: foc/core/protection.hpp, foc/core/watchdog.hpp, foc/core/thermal_limit.hpp, foc/core/brake_chopper.hpp and foc/core/commissioning.hpp; the level this page may state is the minimum of those five. The times, temperatures and budgets this page would otherwise want to quote live in those rows and in their test files -- the example here retypes the same configuration the protection tests use, on purpose, so that what it demonstrates is the shipped behaviour and not a demo-only set of limits.

What this page does not claim: an order of severity among the fault codes; a hardware watchdog, since the latch this page describes arms nothing and reads no register; or any peak voltage and ringing during clamping, which depend on parasitic inductance and ESR that this model does not have.

The trip line is drawn from its own row of data rather than from where the curve reaches zero, because those are two different temperatures and drawing one for the other is exactly failure mode 2.
