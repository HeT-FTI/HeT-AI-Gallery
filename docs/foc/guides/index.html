1. Guides by task

The API reference answers "what does this function take". This section answers the other question: "I have a task; which pieces do I need, and how do they go together." One page per task, not per header.

Every page in this section has the same seven parts, so one you have read teaches you where to look on the next one:

  1. The task -- the question in the words a user would use.

  2. What you need -- the headers, and what each one is for.

  3. A minimal program -- compiled with this repository's own flags, in docs/doxygen/dox/demos/.

  4. Where the numbers come from -- which nameplate field or helper produces each constant, because a retyped gain is a second machine.

  5. How it goes wrong -- the failure modes that compile cleanly.

  6. Evidence -- which claim rows cover the page, and what the page does not claim.

  7. Figure -- produced by docs/demos/make_figures.py, never hand-drawn.

Two rules apply to every page and are worth stating once:

  • The listing *is* the file. Part 3 is a literalinclude of the example in docs/doxygen/dox/demos/, not a copy of it: what the page shows is the translation unit that produced part 7's figure, so the two cannot drift. The one compile command lives in Measured responses instead of being repeated on every page.

  • The evidence level is the minimum of the page's claim rows, and the level itself lives in the claim table in the project README.md. No page in this section repeats a level or a measured number; a number copied into a page is a second source of truth with a shelf life.

  • The figure shows what it shows. Where a page's headline number is not visible in the figure, the page says so rather than choosing a figure that looks like it agrees.

1.2. The figures already on the site

Measured responses holds the SIL traces that the figure step draws on. They are scenario pages rather than task pages: a scenario says "watch the loop do this", a task page says "here is what to wire on your machine".

1.3. Reading the pages in order

The nine pages below are independent on purpose, but a machine does not meet them independently: it is read, checked, aligned, given a torque command, run past base speed, positioned and tripped. One machine, one shift does exactly that, in that order, on one nameplate, and states one number per stage — every one printed by a script that page includes.
