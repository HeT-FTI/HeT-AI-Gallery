Object detection
================

Object detection locates and classifies objects within an image. IE supports
lightweight detector execution on embedded targets through the same static
CNN graph, caller-owned memory, and optional optimized kernels used by other
CNN applications.

Food detection example
----------------------

The food gallery example illustrates an RGB detection pipeline for smart
kitchen and inspection scenarios.

Integration flow
----------------

.. code-block:: text

   Camera frame
   -> model-specific resize and quantization
   -> ie_evoke
   -> ie_erupt
   -> detector output decoding and confidence filtering
   -> bounding boxes for downstream processing

Deployment notes
----------------

The detector is converted from TFLite to Strata/Magma by the associated IE
tooling flow. Input dimensions, class names, anchors, decode rules, confidence
thresholds, and non-maximum suppression are model-specific and must be taken
from the actual model package.

The example demonstrates the integration path only. Detection accuracy, class
count, and target-board frame rate require a model-specific benchmark report;
they are not inferred from this gallery image.
