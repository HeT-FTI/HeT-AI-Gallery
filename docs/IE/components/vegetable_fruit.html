Vegetable and fruit classification

This gallery example demonstrates multi-class camera inference on an embedded device using IE's static CNN execution path.

Integration highlights

  • RGB image preparation using the model's geometry and quantization parameters;

  • Strata/Magma model data in read-only storage;

  • caller-owned activation memory with no runtime heap requirement;

  • scalar fallback and optional optimized CPU kernels;

  • model-specific class mapping and output post-processing.

The gallery image illustrates the application scenario. Class count, accuracy, and latency must be reported from the actual model and target configuration. See Getting started for the integration flow.
